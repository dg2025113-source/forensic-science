##느낀점
# 20124 전서윤
- 느낀 점 : 트리의 깊이가 모델 학습에 미치는 영향을 직접 비교하며 적절한 모델 설정의 중요성을 느꼈음. 포스터 만드는 게 힘들었음.

# 20526 최민지
- 느낀 점 : 기존 모델의 설정을 그대로 사용하는 데 그치지 않고 다른 조건을 적용해 비교하는 과정이 의미 있다고 느꼈음. 실험 결과를 바탕으로 모델의 특성과 한계를 해석하는 태도의 중요성을 배움.

# 20616 안수정
- 느낀 점 : 모델의 최대 깊이를 변화시키며 평가 지표를 비교하는 과정에서 모델 설정에 따라 성능이 달라질 수 있음을 알게 됨. 단순히 높은 성능만 보는 것이 아니라 과대적합 가능성도 고려해야 한다고 느꼈음.
