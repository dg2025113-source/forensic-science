# 1차시 기록 : 팀 구성, 주제 탐색

## 20124 전서윤
- 느낀 점 : 섬유마다 스페그럼이 다르게 나타날 수 있다는 점이 흥미로워 이 주제를 선택했다. 물리에서 배우는 파동과 빛의 특성을 실제 데이터 분석과 연결해 볼 수 있을 것 같다.

## 20526 최민지
- 느낀 점 : 평소에는 적외선 스펙트럼을 자세히 접할 기회가 없었는데, 이를 이용해 섬유의 종류를 구분할 수 있다는 점이 흥미로웠다. 실제 데이터를 분석하면 어떤 결과가 나올지 궁금하다.

## 20616 안수정
- 느낀 점 : 처음에는 섬유의 종류를 적외선 스펙트럼으로 구분할 수 있다는 점이 신기했다. 데이터를 살펴보면서 어떤 기준으로 섬유를 분류하면 좋을지 생각해 볼 수 있었다.
