# 2차시 기록 : 팀 구성, 주제 탐색

## 20124 전서윤
- **오늘 결정한 것:** 분광 스펙트럼 데이터를 활용해 섬유 10종을 분류하는 머신러닝 모델을 제작하기로 했다. 분광 변수 3,451개를 입력 데이터로, 섬유 종류(Type)를 예측 대상으로 설정했다.
- **AI에게 보낸 프롬프트(원문):** 섬유 분광 데이터의 특성을 고려하여 섬유 종류를 분류하는 데 적합한 머신러닝 모델 세 가지를 추천해 줘.
- **AI가 준 것 중 고치거나 버린 것과 그 이유:** 일반적인 분류 모델 추천을 그대로 받아들이기보다, 우리 데이터가 160개 샘플에 3,451개의 분광 변수를 가지고 있다는 점을 고려해 모델을 선정했다.
- **느낀 점:** 데이터의 크기와 변수의 특성을 고려하는 것이 모델을 선택하는 데 중요하다는 것을 알게 되었다.

## 20526 최민지
- **오늘 결정한 것:** 로지스틱 회귀, 서포트 벡터 머신(SVM), 랜덤 포레스트를 후보 모델로 선정하고, 베이스라인 모델과 동일한 조건에서 비교하기로 했다.
- **AI에게 보낸 프롬프트(원문):** 우리 섬유 분광 데이터를 이용해 로지스틱 회귀, SVM, 랜덤 포레스트 모델을 학습하고 성능을 비교하는 코드를 작성해 줘.
- **AI가 준 것 중 고치거나 버린 것과 그 이유:** 같은 시료에서 얻은 반복 측정값이 학습 데이터와 시험 데이터에 동시에 포함되지 않도록 시료 단위로 데이터를 분리했다. 같은 시료의 정보가 양쪽에 들어가면 모델의 성능이 실제보다 높게 평가될 수 있기 때문이다.
- **느낀 점:** 모델의 성능을 공정하게 평가하려면 학습과 시험 데이터를 어떻게 분리하는지도 중요하다는 것을 알게 되었다.

## 20616 안수정
- **오늘 결정한 것:** 세 가지 모델의 정확도와 Macro F1-score 등을 비교하고, 가장 높은 성능을 보인 랜덤 포레스트를 최종 모델 후보로 선정했다.
- **AI에게 보낸 프롬프트(원문):** 세 가지 머신러닝 모델의 평가 결과를 비교하고 혼동 행렬을 이용해 섬유 종류별 분류 결과와 오분류 사례를 분석해 줘.
- **AI가 준 것 중 고치거나 버린 것과 그 이유:** 정확도만으로 모델의 성능을 판단하지 않고 Macro F1-score와 혼동 행렬을 함께 확인했다. 시험 데이터가 40개로 적다는 점도 고려해 결과를 과도하게 일반화하지 않기로 했다.
- **느낀 점:** 랜덤 포레스트가 가장 높은 성능을 보였지만, 적은 데이터로 평가한 결과이므로 추가 검증이 필요하다는 점을 알게 되었다.
