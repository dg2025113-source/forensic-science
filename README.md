## 왜 이 주제인가 (팀이 씁니다)

저희 팀은 경찰 과학수사에서 증거를 분석하는 방법에 관심이 있어 이 주제를 선정했습니다. 범죄 현장에서는 옷이나 천에서 떨어진 작은 섬유가 증거로 발견될 수 있습니다. 섬유마다 화학적 성질이 다르기 때문에 적외선 스펙트럼을 분석하면 섬유의 종류를 구분하는 데 도움이 될 수 있습니다. 그래서 실제 섬유 스펙트럼 데이터를 이용해 컴퓨터가 섬유의 종류를 얼마나 잘 구분하는지 확인하고 싶었습니다. 화학에서 배우는 물질의 성질과 경찰 과학수사를 데이터 분석으로 연결할 수 있다는 점에서 의미가 있다고 생각했습니다.

## 데이터

- 출처: Mendeley Data, *A dataset of infrared (ATR-FTIR) spectra for textile fibres of natural and man-made origin*
- 데이터 주소: https://data.mendeley.com/datasets/rx3fjgz96x/3
- DOI: https://doi.org/10.17632/rx3fjgz96x.3
- 라이선스: CC BY 4.0
- 데이터 설명: 공개된 자료에 따르면 섬유 시료 137개에서 얻은 스펙트럼 160개를 포함합니다.
- 사용 파일: `05_feature_matrix_preprocessed_als_snv_sgd2.csv`
- 예측 대상: `Subtype` (세부 섬유 종류)
- 입력 데이터: 파수에 따른 적외선 스펙트럼 측정값

### 데이터 전처리

- 결측값과 중복값이 있는지 확인합니다.
- 섬유의 종류를 예측하는 데 직접 사용하지 않는 식별 열은 입력 데이터에서 제외합니다.
- 같은 시료에서 측정한 데이터가 학습용 데이터와 시험용 데이터에 동시에 포함되지 않도록 주의합니다.
- 섬유 종류별 데이터 개수를 확인해 특정 종류에 데이터가 지나치게 집중되어 있는지 살펴봅니다.
- 공개된 데이터 설명과 실제 분석 파일의 섬유 종류 수가 일치하는지 확인합니다.

## 방법

저희 팀은 분류 모델을 이용해 적외선 스펙트럼만으로 섬유의 종류를 예측하고자 합니다. 스펙트럼 측정값을 모델에 입력하면 모델이 학습한 특징을 바탕으로 섬유의 종류를 예측합니다. 이후 실제 종류와 예측 결과를 비교해 스펙트럼이 섬유를 구분하는 데 얼마나 도움이 되는지 알아봅니다.

### 분석 과정

1. 데이터 불러오기: CSV 파일을 불러와 데이터의 행과 열, 섬유 종류를 확인합니다.
2. 데이터 전처리: 결측값과 중복값을 확인하고 분석에 필요한 열을 선택합니다.
3. 데이터 분리: 학습용 데이터와 시험용 데이터를 나눕니다. 같은 시료의 측정값이 양쪽에 동시에 들어가지 않도록 합니다.
4. 모델 학습: 여러 분류 모델을 이용해 섬유 종류를 예측합니다.
5. 모델 비교: 정확도와 F1-score 등을 이용해 모델의 성능을 비교합니다.
6. 결과 분석: 혼동 행렬을 통해 어떤 섬유 종류를 잘 구분하고 어떤 종류를 헷갈리는지 확인합니다.
7. 결론 도출: 분석 결과를 바탕으로 적외선 스펙트럼을 이용한 섬유 분류의 가능성과 한계를 알아봅니다.

## 모델 소개 (선택 모델 + 비교 모델 2개)

| 모델 | 원리 | 장점 | 단점 |
|---|---|---|---|
| k-NN | 측정값이 비슷한 데이터의 종류를 참고해 분류합니다. | 원리가 간단하고 이해하기 쉽습니다. | 데이터의 크기와 거리 계산 방식에 영향을 받습니다. |
| 결정 트리 | 측정값을 기준으로 여러 단계로 나누어 분류합니다. | 분류 과정을 비교적 쉽게 이해할 수 있습니다. | 학습 데이터에 지나치게 맞춰질 수 있습니다. |
| 랜덤 포레스트 | 여러 결정 트리의 예측 결과를 종합합니다. | 여러 특징을 종합해 분류할 수 있습니다. | 결과를 하나의 규칙으로 설명하기 어렵습니다. |

실제 분석 결과를 비교한 뒤 가장 적합한 모델을 선택합니다. 성능을 확인하기 전에는 특정 모델이 가장 우수하다고 단정하지 않습니다.

## 한계

- 데이터의 규모가 크지 않아 모든 종류의 섬유에 대해 같은 성능을 보인다고 단정하기 어렵습니다.
- 학습에 사용하지 않은 새로운 섬유나 다른 측정 환경에서는 예측 결과가 달라질 수 있습니다.
- 섬유의 종류가 비슷하거나 데이터가 부족한 경우에는 정확하게 구분하기 어려울 수 있습니다.
- 실제 범죄 현장에서는 섬유에 오염 물질이 묻어 있을 수 있으므로 실험실에서 측정한 스펙트럼과 차이가 발생할 수 있습니다.
- 모델이 섬유의 종류를 예측하더라도 그 결과만으로 특정 사람이나 범죄를 확정할 수는 없습니다. 실제 과학수사에서는 다른 증거와 전문가의 판단이 필요합니다.
